# サンマールHP管理アプリ

HTMLを直接触らずに、サンマール各店舗ページの一部を更新するためのローカル管理アプリです。

## 起動方法

1. `run_admin.bat` をダブルクリックします。
2. ブラウザで `http://127.0.0.1:8765` を開きます。
3. 店舗を選び、内容を修正して保存します。

## 更新できる内容

- 店舗名
- 併設店舗の案内
- 上部タグ
- 店舗情報欄
- Googleマップ埋め込みURL
- 人気メニュー
- メニュー表画像
- 主なメニュー

## 公開まで行う方法

1. 内容を修正して `保存` を押します。
2. `変更確認` を押して、GitHubへ反映前の変更を確認します。
3. `記録メモ` に更新内容を短く書きます。
4. `GitHubへ反映` を押します。
5. 公開ページを開いて表示を確認します。

## 注意

- 保存すると、元のHTMLは `backups` フォルダに自動バックアップされます。
- 保存しただけでは公開HPは変わりません。GitHubへ反映すると公開HPへ反映されます。
- レイアウトや色などのデザインは、この管理アプリからは変更しない想定です。
